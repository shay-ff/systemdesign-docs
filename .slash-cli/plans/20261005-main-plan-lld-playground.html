LLD Practice Playground — Implementation Plan

A new repo (~/dev/lld-playground): Next.js frontend + FastAPI API + a Docker-sandboxed executor, turning the six systemdesign-docs LLD problems into a run-your-code practice tool.

For agentic workers: REQUIRED SUB-SKILL: use subagent-driven-development (recommended) or executing-plans to implement this plan task-by-task. Each task's implementation goes through test-driven-development, which is mandatory for every task that contains logic. Steps use checkbox syntax for tracking.

Goal: Build a working local playground where a user picks one of six LLD problems, writes a Python solution in a browser editor, runs it against a hidden test suite executed in a locked-down Docker container, and sees pass/fail — with the problem's design-discussion content unlocking only after a pass.

Architecture: Three services. A public API service (FastAPI) serves problem content and accepts submissions but never touches Docker directly. A separate executor service (FastAPI) is the only component that runs user code, via a per-submission, network-disabled, non-root, read-only-rootfs Docker container built from a pinned runner image with the six problems' hidden tests baked in. A frontend (Next.js) talks only to the API service.

Tech Stack: Next.js (App Router) + @monaco-editor/react for the frontend. FastAPI + slowapi (rate limiting) for both backend services. Docker CLI invoked via subprocess (argv lists, never shell=True) for sandboxing. pytest for all Python tests.

Global Constraints

  • Source of problem content: ~/dev/systemdesign-docs/01-ll-designs/<problem>/{README.md, explanation.md, solutions/python/*.py} — copied, never fetched at runtime (per spec's content-sync decision).
  • Submissions are Python only. Each problem's hidden tests enforce a specific class/method contract, listed per-task below — these are a deliberate, deterministic simplification of the full reference implementations (e.g. synchronous message delivery instead of threaded, an injectable clock for the rate limiter) so automated grading has no timing flakiness. The simplified contract is shown to the user alongside the problem statement as "Required signature," separate from the synced README.md/explanation.md text, which stays untouched.
  • No shell-string interpolation anywhere user-submitted code or its path touches a subprocess call (validation/untrusted-input command-execution rule) — always pass argv lists.
  • Executor container flags required on every run: --network none, --read-only, --cap-drop ALL, --security-opt no-new-privileges, non-root --user, explicit --cpus/--memory/--pids-limit, plus a hard subprocess-level timeout with a docker kill fallback (containers/hardening).
  • Runner base image is pinned to an exact tag (python:3.12.7-slim), never a floating tag like latest or 3.12-slim.
  • Frontend is pinned to Next.js 14.x (create-next-app@14). Next.js 15 made route params an async Promise — the plan's page components read params synchronously, which only holds on the 14.x App Router.
  • No accounts, no server-side session. The solved flag the frontend sends to unlock explanation.md is a UX gate the user could bypass themselves — acceptable for a single-user tool, called out in the root README so it's never mistaken for a security control later.
  • Scaffolding steps (creating a directory layout, running a project generator) have no meaningful "failing test" and use a setup-step + verification-step shape instead of red/green TDD. Every task containing logic (hidden tests, the executor, API routes, rate limiting) follows full TDD: failing test, run to confirm failure, minimal implementation, run to confirm pass, commit.

# LLD Practice Playground

Write Python solutions to classic LLD problems (LRU cache, rate limiter,
bloom filter, URL shortener, consistent hashing, message queue) and run
them against hidden tests in a sandboxed Docker container.

## Services
- `frontend/` — Next.js UI
- `backend/` — public FastAPI API (problems, submissions)
- `executor/` — the only service that runs user code, in a locked-down
  per-submission Docker container (non-root, read-only rootfs, no network)

## Security note
There are no user accounts. The "solved" flag that unlocks a problem's
design-discussion tab is set by the frontend and is a UX convenience, not
an enforced security boundary — do not rely on it if accounts are ever
added later.

The `executor` service has the host's Docker socket mounted into it
(`/var/run/docker.sock`) so it can launch per-submission sandbox
containers. That grants `executor` root-equivalent access to the host —
acceptable for a local, single-user, localhost-only tool, but this stack
must never be exposed beyond localhost or to multiple users without
replacing direct Docker-socket access with a properly isolated job runner
(gVisor, Firecracker, or a managed sandboxed-execution API).

## Content source
Problem statements and reference solutions are copied from
`systemdesign-docs/01-ll-designs/` via `scripts/sync_content.py`. Re-run
that script by hand to pull upstream changes; nothing syncs automatically.

# scripts/sync_content.py
"""Copy problem content from systemdesign-docs into this repo.

Run by hand: python scripts/sync_content.py
Re-run any time the upstream problem content changes; nothing syncs
automatically (see Global Constraints in the implementation plan).
"""
import pathlib
import shutil

PROBLEMS = [
    "lru_cache",
    "rate_limiter",
    "bloom_filter",
    "url_shortener",
    "consistent_hashing",
    "message_queue",
]

DEFAULT_SOURCE_ROOT = pathlib.Path("~/dev/systemdesign-docs/01-ll-designs").expanduser()
DEFAULT_DEST_ROOT = pathlib.Path(__file__).resolve().parent.parent / "backend" / "content" / "problems"


def sync(source_root: pathlib.Path = DEFAULT_SOURCE_ROOT, dest_root: pathlib.Path = DEFAULT_DEST_ROOT) -> None:
    for problem in PROBLEMS:
        src_dir = source_root / problem
        dest_dir = dest_root / problem
        dest_dir.mkdir(parents=True, exist_ok=True)

        shutil.copy2(src_dir / "README.md", dest_dir / "README.md")

        explanation_src = src_dir / "explanation.md"
        if explanation_src.exists():
            shutil.copy2(explanation_src, dest_dir / "explanation.md")

        python_src = src_dir / "solutions" / "python"
        python_dest = dest_dir / "reference_python"
        if python_dest.exists():
            shutil.rmtree(python_dest)
        shutil.copytree(python_src, python_dest)

        print(f"synced {problem}")


if __name__ == "__main__":
    sync()

# backend/app/problems.py
import pathlib
from dataclasses import dataclass

CONTENT_ROOT = pathlib.Path(__file__).resolve().parent.parent / "content" / "problems"


@dataclass(frozen=True)
class ProblemMeta:
    id: str
    title: str
    summary: str


@dataclass(frozen=True)
class ProblemContent:
    id: str
    statement: str
    required_signature: str
    explanation: str | None


PROBLEMS: list[ProblemMeta] = [
    ProblemMeta("lru_cache", "LRU Cache", "O(1) get/put cache with least-recently-used eviction."),
    ProblemMeta("rate_limiter", "Rate Limiter", "Token-bucket request throttling."),
    ProblemMeta("bloom_filter", "Bloom Filter", "Space-efficient probabilistic set membership."),
    ProblemMeta("url_shortener", "URL Shortener", "Shorten and expand URLs with a generated code."),
    ProblemMeta("consistent_hashing", "Consistent Hashing", "Distribute keys across nodes with minimal redistribution."),
    ProblemMeta("message_queue", "Message Queue", "Topic-based publish/subscribe delivery."),
]

_PROBLEM_IDS = {p.id for p in PROBLEMS}

REQUIRED_SIGNATURES: dict[str, str] = {
    "lru_cache": (
        "class LRUCache:\n"
        "    def __init__(self, capacity: int): ...\n"
        "    def get(self, key: int) -> int: ...  # -1 if missing\n"
        "    def put(self, key: int, value: int) -> None: ..."
    ),
    "rate_limiter": (
        "class TokenBucket:\n"
        "    def __init__(self, capacity: int, refill_rate: float,\n"
        "                 clock: Callable[[], float] = time.time): ...\n"
        "    def allow_request(self, tokens_requested: int = 1) -> bool: ..."
    ),
    "bloom_filter": (
        "class BloomFilter:\n"
        "    def __init__(self, expected_elements: int, false_positive_rate: float = 0.01): ...\n"
        "    def add(self, element: str) -> None: ...\n"
        "    def contains(self, element: str) -> bool: ..."
    ),
    "url_shortener": (
        "class URLShortener:\n"
        "    def shorten(self, long_url: str) -> str: ...  # returns a short code\n"
        "    def expand(self, short_code: str) -> str | None: ..."
    ),
    "consistent_hashing": (
        "class ConsistentHash:\n"
        "    def __init__(self, virtual_nodes: int = 3): ...\n"
        "    def add_node(self, node_id: str) -> None: ...\n"
        "    def remove_node(self, node_id: str) -> None: ...\n"
        "    def get_node(self, key: str) -> str | None: ..."
    ),
    "message_queue": (
        "class MessageQueue:\n"
        "    def publish(self, topic: str, payload: str) -> str: ...  # returns message id\n"
        "    def subscribe(self, topic: str, callback: Callable[[str], None]) -> None: ...\n"
        "    # delivery is synchronous: publish() invokes every subscribed callback\n"
        "    # for that topic before returning."
    ),
}


def get_problem_content(problem_id: str, include_explanation: bool = False) -> ProblemContent | None:
    if problem_id not in _PROBLEM_IDS:
        return None

    problem_dir = CONTENT_ROOT / problem_id
    statement = (problem_dir / "README.md").read_text()

    explanation = None
    if include_explanation:
        explanation_path = problem_dir / "explanation.md"
        if explanation_path.exists():
            explanation = explanation_path.read_text()

    return ProblemContent(
        id=problem_id,
        statement=statement,
        required_signature=REQUIRED_SIGNATURES[problem_id],
        explanation=explanation,
    )

    return {"status": "ok"}


@app.get("/problems")
def list_problems() -> list[dict]:

@app.get("/problems/{problem_id}")
def get_problem(problem_id: str, solved: bool = False) -> dict:
    content = get_problem_content(problem_id, include_explanation=solved)
    if content is None:
        raise HTTPException(status_code=404, detail="Problem not found")

        "id": content.id,
        "statement": content.statement,
        "required_signature": content.required_signature,
    }
    if content.explanation is not None:
        result["explanation"] = content.explanation
    return result

import sys
import pathlib

sys.path.insert(0, str(pathlib.Path(__file__).resolve().parent.parent))

from hidden_tests.test_lru_cache import TESTS


class BrokenLRUCache:
    def __init__(self, capacity):
        self.capacity = capacity

    def get(self, key):
        return -1  # always misses - should fail eviction/recency tests

    def put(self, key, value):
        pass  # no-op - should fail every test


class ReferenceLRUCache:
    def __init__(self, capacity: int):
        self.capacity = capacity
        self.cache: dict[int, int] = {}
        self.order: list[int] = []

    def get(self, key: int) -> int:
        if key not in self.cache:
            return -1
        self.order.remove(key)
        self.order.append(key)
        return self.cache[key]

    def put(self, key: int, value: int) -> None:
        if key in self.cache:
            self.order.remove(key)
        elif len(self.cache) >= self.capacity:
            oldest = self.order.pop(0)
            del self.cache[oldest]
        self.cache[key] = value
        self.order.append(key)


def test_broken_stub_fails_at_least_one_hidden_test():
    failures = []
    for test_fn in TESTS:
        try:
            test_fn(BrokenLRUCache)
        except AssertionError:
            failures.append(test_fn.__name__)
    assert failures, "expected the broken stub to fail at least one test"


def test_reference_implementation_passes_every_hidden_test():
    for test_fn in TESTS:
        test_fn(ReferenceLRUCache)  # raises AssertionError on failure

import sys
import pathlib

sys.path.insert(0, str(pathlib.Path(__file__).resolve().parent.parent))

from hidden_tests.test_rate_limiter import TESTS


class ReferenceTokenBucket:
    def __init__(self, capacity, refill_rate, clock=None):
        import time as _time
        self.capacity = capacity
        self.tokens = float(capacity)
        self.refill_rate = refill_rate
        self.clock = clock or _time.time
        self.last_refill = self.clock()

    def allow_request(self, tokens_requested: int = 1) -> bool:
        now = self.clock()
        elapsed = now - self.last_refill
        self.last_refill = now
        self.tokens = min(self.capacity, self.tokens + elapsed * self.refill_rate)
        if self.tokens >= tokens_requested:
            self.tokens -= tokens_requested
            return True
        return False


class BrokenTokenBucket:
    def __init__(self, capacity, refill_rate, clock=None):
        pass

    def allow_request(self, tokens_requested: int = 1) -> bool:
        return True  # always allows - should fail the exhaustion test


def test_broken_stub_fails_at_least_one_hidden_test():

class ReferenceConsistentHash:
    def __init__(self, virtual_nodes: int = 3):
        import bisect
        self.virtual_nodes = virtual_nodes
        self.ring: dict[int, str] = {}
        self.sorted_hashes: list[int] = []
        self.nodes: set[str] = set()
        self._bisect = bisect

    def _hash(self, key: str) -> int:
        return hash(key) & 0x7FFFFFFF

    def add_node(self, node_id: str) -> None:
        if node_id in self.nodes:
            return
        self.nodes.add(node_id)
        for i in range(self.virtual_nodes):
            h = self._hash(f"{node_id}:{i}")
            self.ring[h] = node_id
            self._bisect.insort(self.sorted_hashes, h)

    def remove_node(self, node_id: str) -> None:
        if node_id not in self.nodes:
            return
        self.nodes.remove(node_id)
        for i in range(self.virtual_nodes):
            h = self._hash(f"{node_id}:{i}")
            self.ring.pop(h, None)
            if h in self.sorted_hashes:
                self.sorted_hashes.remove(h)

    def get_node(self, key: str) -> str | None:
        if not self.sorted_hashes:
            return None
        h = self._hash(key)
        idx = self._bisect.bisect_right(self.sorted_hashes, h)
        if idx == len(self.sorted_hashes):

# executor/runner_image/harness.py
"""Runs inside the sandboxed container. Imports the submitted module from
the path given as argv[1], runs the hidden tests for PROBLEM_ID against
it, and prints one JSON line to stdout. Never touches the network or
anything outside the path it's given.
"""
import importlib
import importlib.util
import json
import os
import sys

PROBLEM_CLASS = {
    "lru_cache": "LRUCache",
    "rate_limiter": "TokenBucket",
    "bloom_filter": "BloomFilter",
    "url_shortener": "URLShortener",
    "consistent_hashing": "ConsistentHash",
    "message_queue": "MessageQueue",
}


def load_submission(path: str):
    spec = importlib.util.spec_from_file_location("submission", path)
    module = importlib.util.module_from_spec(spec)
    spec.loader.exec_module(module)
    return module


def main() -> None:
    problem_id = os.environ["PROBLEM_ID"]
    submission_path = sys.argv[1]
    class_name = PROBLEM_CLASS[problem_id]

    try:
        submission = load_submission(submission_path)
    except Exception as exc:  # noqa: BLE001 - deliberately broad: any
        # error in untrusted code becomes a structured result, not a crash.
        print(json.dumps({"passed": False, "error": "import_error", "message": str(exc)}))
        return

    if not hasattr(submission, class_name):
        print(json.dumps({
            "passed": False,
            "error": "missing_class",
            "message": f"Expected class {class_name} not found in submission",
        }))
        return

    submitted_cls = getattr(submission, class_name)
    test_module = importlib.import_module(f"hidden_tests.test_{problem_id}")

    results = []
    for test_fn in test_module.TESTS:
        name = test_fn.__name__
        try:
            test_fn(submitted_cls)
            results.append({"name": name, "passed": True})
        except AssertionError as exc:
            results.append({"name": name, "passed": False, "message": str(exc)})
        except Exception as exc:  # noqa: BLE001 - same reasoning as above
            results.append({"name": name, "passed": False, "message": f"{type(exc).__name__}: {exc}"})

    print(json.dumps({"passed": all(r["passed"] for r in results), "results": results}))


if __name__ == "__main__":
    main()

# executor/app/docker_runner.py
"""Runs one user submission in a locked-down, per-submission Docker
container. Never builds a shell string from user input - the submission
is written to a file and Docker is invoked with an argv list.
"""
import json
import os
import subprocess
import tempfile
import uuid

IMAGE = "lld-runner:latest"
TIMEOUT_SECONDS = 10


def run_submission(problem_id: str, code: str) -> dict:
    run_id = uuid.uuid4().hex[:12]
    container_name = f"lld-run-{run_id}"

    with tempfile.TemporaryDirectory() as tmp_dir:
        submission_path = os.path.join(tmp_dir, "submission.py")
        with open(submission_path, "w") as f:
            f.write(code)
        os.chmod(submission_path, 0o444)

        cmd = [
            "docker", "run", "--rm",
            "--name", container_name,
            "--network", "none",
            "--read-only",
            "--tmpfs", "/tmp:rw,size=10m,mode=1777",
            "--cpus", "0.5",
            "--memory", "128m",
            "--pids-limit", "64",
            "--cap-drop", "ALL",
            "--security-opt", "no-new-privileges",
            "--user", "runner",
            "-v", f"{submission_path}:/sandbox/submission.py:ro",
            "-e", f"PROBLEM_ID={problem_id}",
            IMAGE,
            "/sandbox/submission.py",
        ]

        try:
            proc = subprocess.run(cmd, capture_output=True, text=True, timeout=TIMEOUT_SECONDS)
        except subprocess.TimeoutExpired:
            subprocess.run(["docker", "kill", container_name], capture_output=True, text=True)
            return {"passed": False, "error": "timeout", "message": f"Execution exceeded {TIMEOUT_SECONDS}s"}

        return _parse_harness_output(proc)


def _parse_harness_output(proc: subprocess.CompletedProcess) -> dict:
    output = proc.stdout.strip()
    if not output:
        return {"passed": False, "error": "runtime_error", "message": proc.stderr[-2000:]}
    try:
        last_line = output.splitlines()[-1]
        return json.loads(last_line)
    except (json.JSONDecodeError, IndexError):
        return {
            "passed": False,
            "error": "harness_error",
            "message": (output + proc.stderr)[-2000:],
        }
