# Learning Guide Navigation

Use this guide to choose a starting point and find related material.

## Choose a Path

### New to System Design

Start with [Foundations](00-foundations/README.md), then build a component such
as an [LRU cache](01-ll-designs/lru_cache/README.md).

### Preparing for Interviews

Read the [Interview Prep](04-interview-prep/README.md) material, then use the
[4-Week Crunch Plan](05-study-plan/crunch-plan.md) if you need a shorter
schedule.

### Building Examples

Run the services in [Runnable Examples](03-implementations/README.md) and
review the related design documents.

### Following a Structured Plan

Use the [6-week study plan](05-study-plan/study_plan.md) and track progress with
the listed milestones.
